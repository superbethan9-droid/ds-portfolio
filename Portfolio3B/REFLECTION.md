For portfolio2B, I created 2 applications using a priority task scheduler and a word frequency counter. The main goal was to use my minheap and hashtable to compare their results to the stl containers. This assignment helped me better understand how the use data structures and stuff. For the priority task scheduler I made a task structure cintaining a name and priority value. I used my MinHeap to organize tasks to that the task with the lowest priority number would be processed first, I implimented the ADD, NEXT, and LIST commands to let users insert tasks to get the next task and view their pending tasks. I also used std::priority_queue to verify that my MinHeap made the right extraction order and when tested all three passed. For the word frequency counter I used my HashTable to count how many times a specific word would appear in a text. The program converts words to lowercase and separate words using a symbol. I also compared these results against std::unordered_map to make sure it was correct and when tested all passed. One challenge I came against was debugging the errors that came up when I was compiling stuff especially the word frequency counter. I just made a bunch of spelling errors. I fixed them by looking at the compiling error messages that tell me where and what the error is. If I were to improve this project I would add more tests that involve bigger text files and tasks with matching priorities and the punctiation. Overall, this portfolio assignment strengthed my understanding of heaps, hash tables, and STL containers, I leared how to use data structures to help with actual problems and how to verify my programs work.
