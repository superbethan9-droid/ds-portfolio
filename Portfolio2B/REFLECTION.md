In Portfolio2B I started by creating a contact structure that stores a persons first and last name with their phone number. Then I made comparison operators so the contacts would be organized alphabetically by last name and if they have the same last name it uses first names to sort, after that I implemented functions for ADD, LOOKUP, DELETE, LIST, and COUNT. At the end I made a command loop that lets users interact with the directory by typing in commands. One of the challenges I found was making sure the contact directory worked with the BST and I had to understand how the comparison operators affected the order of the contacts and how to handle multiple people witht he same last name. Other challenges were just the errors that I encounter like missing a bracket somehwere or making sure they are formatted correctly with the right amount of spaces or tabs. To solve these issues I had to review my code carefully and make sure everything is in the right spot spelled correctly. I used test cases with expected and the actual results to verify that each operator worked. I also tested contacts with the same last name to make sure they printed in the right order with the first names being alphabetically sorted. After all this I tested commands with different contacts and checked that the delete and lookup worked and checked with valgrind at the end. If I started this project again I would organize my tests as soon as possible so it's easier to look at and figure out where I had a syntax error at and what was wrong. Overall, this project helped me understand how a BST can be used in a real world situation with a real program I also improved my debugging skills training my eyes to look out for obvious bugs.
